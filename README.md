# AI Campus Readiness System

A full-stack platform that evaluates campus placement readiness using AI and machine learning.

This repository includes:

- A **React + Tailwind** frontend dashboard
- A **Flask REST API** backend with ML-powered endpoints
- **Machine learning models** for readiness scoring, domain prediction, and placement probability
- **Resume analyzer** and **career chatbot** AI features
- Data generation scripts and pre-built datasets
